# 📚 Project Overview

Zotero is a Windows reference management utility designed for collecting, organizing, and working with research sources.

The application provides a structured library for references, bibliographic information, notes, and associated documents. It can help users maintain research materials while preparing academic, professional, or personal writing projects.

Zotero brings source organization, citation management, document storage, and research notes into one dedicated workspace.

- Maintain structured research collections
